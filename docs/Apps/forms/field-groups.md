Field groups control how form fields are arranged inside a form.

> 👍 Form block
>
> The [Form block](doc:form-block) can auto-generate fields for you. Use field groups when you need more control over layout.

## Update form fields

Use `Update form fields` to generate fields from the form schema or refresh them after the schema changes.

Field groups must be nested inside a `Form` component for this to work.

## Layout

Use field groups to control how fields are displayed. Available layouts include:

* One column
* Multiple columns
* Main with sidebar

## Label alignment

Choose whether labels are aligned `Left` or `Above`.

Layout options only apply when labels are aligned `Above`.
