Use the app URL directly when you want to bypass the Budibase portal.

## Use a pretty URL

You can set a custom path for an unpublished app.

The URL format is:

`<your-budibase-url>/yourprettyurl`

## Find the app URL

Open the app in the portal and copy the app URL from the app details.

If the app is unpublished, you can also edit the name and URL there.

## Bookmark the app

Save the app URL as a browser bookmark to open the app directly in the future.
