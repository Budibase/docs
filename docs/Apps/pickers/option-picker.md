Use the Options Picker to let a user select a single value from a list.

Add it inside a [Form](doc:forms).

## Option sources

You can populate options from:

* Schema
* Data provider
* Custom options

## Use schema options

Use schema options when the values are stored on the form's table schema.

This works best for static values that do not change often.

## Use a data provider

Use a data provider when the options should come from another datasource.

You need a provider, a label column, and a value column.

## Use custom options

Use custom options when you want to define the labels and values manually.

This is useful for public forms, API-driven values, and other custom workflows.

## Other settings

* Autocomplete
* Radio button type
* Horizontal layout
* Field
* Name
* Placeholder
* Default value
