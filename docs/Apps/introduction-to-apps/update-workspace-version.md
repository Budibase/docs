With Budibase, you can have workspaces running on different client versions. Some features will not be available unless you update to the latest version. Other changes, such as backend automations and configurations, will still update regardless of which workspace version you are on.

You can revert your workspace client version if you're experiencing issues with the latest one. You revert your client version by going to **Settings** -> **General** and scroll down until you see **Client version**
