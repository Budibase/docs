The Rating component allows users to visually select a rating using icons such as stars or hearts. It's fully customisable with settings for the number of icons, size, icon type, and colour variants. This component functions as a form field and is compatible with number-type fields, making it great for collecting user feedback in reviews, feedback, or surveys.

## Custom settings

| Setting             | Description                                                             | Default   |
| ------------------- | ----------------------------------------------------------------------- | --------- |
| **Number of Stars** | Determines how many icons (stars/hearts) are shown.                     | `5`       |
| **Size**            | Sets the size of the icons. Options include: `XS`, `S`, `M`, `L`, `XL`. | `L`       |
| **Icon Type**       | Chooses between icon styles. Currently supports: `star`, `heart`.       | `star`    |
| **Colour Variant**  | Select from preset colour schemes or define a custom colour.            | `Primary` |
