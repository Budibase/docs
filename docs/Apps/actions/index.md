Budibase actions fall into four groups: data, application, form, and logic.

## Data actions

As the title implies, these actions revolve around data. They involve tasks like retrieving data from different sources (like REST APIs or external databases), refreshing data sources, or making changes to data (such as updating rows in a database). You can view this [here.](doc:data-actions)

## Application actions

These actions can happen at any time in your application. They include displaying notifications, opening side panels or pop-up windows, logging out users, and starting automations. See [Application actions](doc:application-actions).

## Form actions

Form actions manipulate different parts of a form. The main actions are `Update Field Value`, `Validate Form`, `Change Form Step`, and `Clear Form`. See [Form actions](doc:form-actions).

## Logic actions

Currently there is only one logic action: [Continue If / Stop if](https://docs.budibase.com/docs/chaining-actions#continue-if--stop-if).
