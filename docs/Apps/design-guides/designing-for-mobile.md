Design screens so they still work on smaller devices.

## Responsive behavior

Budibase uses breakpoints to switch layouts for different screen sizes.

You cannot edit the default breakpoints.

## Use layout components

Use Containers, flex wrap, and grid layouts to control how content responds on smaller screens.

## Adjust settings by device

You can conditionally change component settings based on the current device.

This is useful for changing labels, spacing, or visibility on mobile.

## Use compact navigation

Use a hamburger menu or other compact navigation when space is limited.

Budibase adds the mobile menu automatically for side navigation and top navigation layouts.
