Sections were layout components that arranged nested content in preset column structures.

This page is deprecated. Use Containers and other layout components instead.

## Common patterns

Sections were often used for:

* Main and sidebar layouts
* Two-column layouts
* Three-column layouts
* Repeating content across a screen

## Legacy guidance

Older apps may still contain sections in existing screens.

If you are editing one, keep the nested content structure aligned with the section type.
