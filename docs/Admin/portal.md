When you sign in to Budibase, you will be presented with the Budibase portal. Depending on your user role, you will see either the **admin portal**, **builder portal** or the **standard portal.**

## Admin portal

Admin users have access to all of the functions of the budibase portal, such as user and OAuth administration, email templates and organisation level settings. Admins can also build, deploy and manage applications.

<Image align="center" src="https://files.readme.io/5b2b270-Screenshot_2023-11-02_at_14.49.34.png" />

## Builder portal

<Glossary>Builder</Glossary>s can build, deploy and manage applications. They do not however have access to the admin configuration sections of the portal.

<Image align="center" src="https://files.readme.io/a30793b-Screenshot_2023-09-27_at_12.16.55.png" />

## Standard portal

In the standard portal you can only see the list of deployed applications that you have access to.\
You will not see the user admin options, dev apps or deployment options that are available in dev or admin mode.\
The standard portal acts as a landing page for users to use budibase apps created by users with builder permissions.

![](https://files.readme.io/25e13ef-portal-3.png "portal-3.png")

## Export and Import an App

From the list of Apps on the portal pages you can export the design and data of an existing app. For details see our [exporting and importing an application](/docs/export-and-import-apps) documentation.
