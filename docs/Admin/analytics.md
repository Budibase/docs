[block:api-header]
{
  "title": "Why we use Analytics"
}
[/block]
Analytics allows us to gain more meaningful insight into what features of the product are a hit and more importantly helps us to identify where we need to make improvements.

Another reason we use analytics is for feature flagging which allows us to provide early access to feature previews to users who choose to have analytics turned on. 


[block:api-header]
{
  "title": "Anonymous Events"
}
[/block]
All events created within budibase are anonymised, meaning that we don't collect personal details like email addresses. To see what events are used see the [Event Reference](doc:event-reference).
[block:api-header]
{
  "title": "Tools that we use"
}
[/block]
Budibase partners with [PostHog](https://posthog.com) to provide usage analytics, an open source platform for data analysis. 
[block:api-header]
{
  "title": "Opting in or out"
}
[/block]
To choose whether to opt-in or opt-out of analytics visit the `Organisation` page in the portal.
