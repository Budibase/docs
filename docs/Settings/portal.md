## User portal

In the user portal you can only see the list of deployed applications that you have access to.  
You will not see the user admin options, dev apps or deployment options that are available in dev or admin mode.  
The standard portal acts as a landing page for users to use budibase apps created by users with builder permissions. Creators or Admin users can access this by closing the developer mode from the profile-menu found by clicking the user's own name in the bottom-left of the builder-screen.
