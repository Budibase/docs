Use the User settings menu to update your account details and developer options. Open it from your profile dropdown in the top right of the builder.

### Update user information

Update your first and last name. This helps with email templates and makes it easier for other people in your organisation to identify you.

### Update password

Use this option to change your password.

### Toggle developer mode (Developer/Admin users only)

As a developer or admin, you can switch between **developer mode** and **standard mode**. For more detail, see [Portal](doc:portal).

### View API key

Displays the API key and a copy button. Use this value as the required header for the [Public API](doc:public-api).
