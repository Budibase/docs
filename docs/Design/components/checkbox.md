The `checkbox` component allows you to let the user check a box, or not. 

![810](https://files.readme.io/a61ec50-checkbox.png "checkbox.png")

## Adding a checkbox

The `Checkbox` component requires a [Form](doc:forms) component to be a parent.

To add a `Checkbox` component to your app, you need to click `Form > Checkbox`

![240](https://files.readme.io/f9ae263-adding-checkbox.png "adding-checkbox.png")

## Customizing the Checkbox

To customize the checkbox, there are several settings in the <Glossary>Settings Panel</Glossary> that can be used.
