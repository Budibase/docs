This section covers the available AI Automation steps you can add to your workflows. Each step uses an AI model to process text or images according to your needs.

For a quick introduction to setting up AI in your workflows, see the [Quickstart AI Guide](docs:quickstart-budibase-ai).

## Available steps:

* Classify Text – Assign text to a category from your list.
* Translate – Translates text into a target language.
* Summarise – Creates a short, medium, or long summary of your text.
* Generate Text – Generates new text in a specified style or format.
* LLM Prompt – Sends a custom prompt directly to the Large Language Model for flexible outputs.
