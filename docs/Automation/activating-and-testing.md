Automations are only active in published apps, however you can test each automation by clicking ‘Run test’.

You will be prompted to provide test data, with the exception of web-hook and cron triggers.

![1424](https://files.readme.io/828145f-Screenshot_2022-03-16_at_13.35.18.png "Screenshot 2022-03-16 at 13.35.18.png")

After running the test, you will be able view the response - green indicating success. 

If your automation does not run as expected then check that all input mustache syntax is valid and any filters put in place should pass.
