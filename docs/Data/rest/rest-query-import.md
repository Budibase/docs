The REST query import feature allows you to import one or more queries at a time. 

 

## Import Formats

The supported formats for import are:

- Swagger 2.0 / OpenAPI 2.0 (YAML or JSON)
- Swagger 3.0 / OpenAPI 3.0 (YAML or JSON)
- CURL

 

***

  

## Import Sources

### URL

Enter the link to your API documentation.

![](https://files.readme.io/5f983df-Screenshot_2021-12-21_at_16.19.06.png "Screenshot 2021-12-21 at 16.19.06.png")

  

### File

Upload a file containing your API documentation.

![](https://files.readme.io/f809121-Screenshot_2021-12-21_at_16.19.14.png "Screenshot 2021-12-21 at 16.19.14.png")

  

### Text

Enter the documentation string directly.

![](https://files.readme.io/1964b06-Screenshot_2021-12-21_at_16.19.22.png "Screenshot 2021-12-21 at 16.19.22.png")

## Query location

When the import completes the new queries will be displayed in the data source

![](https://files.readme.io/b70fe0c-Screenshot_2021-12-21_at_16.29.33.png "Screenshot 2021-12-21 at 16.29.33.png")

  

***

  

## Import into a new datasource

To import queries into a new datasource use

- Data > Sources > Add > Rest > Import

![](https://files.readme.io/7211f06-rest-query-import-add-new-datasource.png "rest-query-import-add-new-datasource.png")

  

***

  

## Import into an existing datasource

To import queries into a new datasource use

- Data > Sources > Select REST source > Queries > Import

![](https://files.readme.io/fb13a16-Screenshot_2021-12-21_at_16.25.47.png "Screenshot 2021-12-21 at 16.25.47.png")
