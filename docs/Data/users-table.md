The **Users** table is a special <<glossary:Budibase DB>> table that stores all of the users that have access to the app. 

It has a unique icon to differentiate it from other tables: 

![](https://files.readme.io/1bec690-Screenshot_2022-05-04_at_15.02.08.png "Screenshot 2022-05-04 at 15.02.08.png")

Unlike regular tables, you cannot add rows to the users table. In addition, rows cannot be deleted so that the audit trail remains intact even if a users' access is revoked.

[User Management](doc:user-management) is handled through the [Admin Portal](doc:portal).

The standard columns include:

![](https://files.readme.io/a987a36-Screenshot_2022-05-04_at_15.15.00.png "Screenshot 2022-05-04 at 15.15.00.png")

## Created By / Updated By columns

Every time an internal table is created, two auto-columns are added to the Users table:

- [table name]-Created By
- [table name]-Updated By

These can be used to <a href="https://docs.budibase.com/docs/fetching-data#display-user-specific-data">display user specific data</a> for the currently logged-in user.

When a row is created through the UI, the user will appear in the 'Created By' column. This is also true of an updated row, where the user will get automatically saved to the 'Updated By' column. 

![](https://files.readme.io/9dc955a-Screenshot_2022-05-12_at_14.14.24.png "Screenshot 2022-05-12 at 14.14.24.png")

> 🚧 Autogenerated column
> 
> The wand icon indicates that this column is autogenerated and auto-populated.  
> The values cannot be overwritten or saved manually.

## Custom columns

Whilst you cannot edit the standard columns or the auto-columns, you can create and edit custom columns. 

This can be useful for adding user metadata innate to your app, [formulas](doc:formula), or any other <a href="https://docs.budibase.com/docs/budibasedb#data-types">data type</a> you want.  

## Edit roles

You can also add custom roles to your app. More information [here](https://docs.budibase.com/docs/user-roles#adding-custom-roles).

## Current User bindings

There are globally available [Bindings](doc:bindings) for every column in the Users table, including the custom columns. 

<img src="https://files.readme.io/a1428ab-Screenshot_2022-05-04_at_11.24.06.png" />

For example, these can be used to display the name of the currently logged-in user, or [Add filtering](doc:searchfilter-data) on the **\_id** to get related user data.

### OAuthToken

When the user logs in using SSO, an [OAuth token](https://docs.budibase.com/docs/authentication-and-sso#using-the-oauth-token) will be available for use in API headers.
